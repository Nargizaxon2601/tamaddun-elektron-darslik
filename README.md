# TAMADDUN — Har hikoya bir saboq

Boshlang‘ich sinf o‘quvchilari uchun interaktiv elektron darslik. Tarbiya va Texnologiya fanlari bo‘yicha darslar "sarguzasht xaritasi" ko‘rinishida o‘tiladi.

## Ishga tushirish

Hech narsa o‘rnatish shart emas. `index.html` faylini brauzerda oching.

## Tuzilma

| Fayl | Vazifasi |
|------|----------|
| `index.html`, `app.js`, `style.css` | Bosh sahifa |
| `darslar.html`, `darslar.js`, `darslar.css` | Asosiy ilova: sinf → fan → chorak xaritasi → dars |
| `texnologiya-1-dars-01.html`, `dars-sahifa.*` | Eski prototip dars sahifasi |
| `images/` | Dars rasmlari |
